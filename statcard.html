Rows & Columns

Click any title, header, or stat cell directly on the card to edit it. Each column has its own small photo box for a headshot — click it to add or replace that player's photo, great for comparing multiple players side by side. Use the color square under each label to recolor that column's numbers. Hover a row to see its remove (×) button.

Stat Template

Loading a template replaces all current rows with that template's stat labels (values reset to 0) — it keeps your current columns as-is. The Statcast template auto-switches the card to Percentile Bars style below and starts blank — add your own stat rows with any label you want.

Card Style

In Percentile Bars mode, each row shows a small editable number next to the bar for the actual stat value (e.g. ".270" or "94 mph"), plus the percentile bar itself — drag anywhere on the bar to slide it to a value, or click the badge and type a number directly; both stay in sync automatically. Everything here is entered by hand; nothing is calculated for you.

Convert a Single Row

Pick a row above, then choose one of the two buttons — no confirmation popup, it applies right away. Rows can be mixed: some as plain numbers, others as percentile bars, on the same card.

Save & Load

This card auto-saves in your browser as you work — reopening this page later picks up right where you left off.
Export gives you a small file with the whole card — every row, column, color, team, and photo. Email it to yourself or save it anywhere, then use "Load Progress" on any device/browser to pick up exactly where you left off.

Import CSV

CSV should have players as rows and stats as columns (a typical spreadsheet export) — the first column in each row is used as that player's column name.
Check which rows become columns, in the order you want them (up to 6). Each CSV column (other than the first) becomes one new stat row, with every selected player's value placed in that same row.

Export

Exports exactly what's shown on the card — controls, buttons, and swatches are excluded automatically.
